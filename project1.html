Database Management System for College Event Website

view on GitHub

Implemented a web-based application that allows students to register for/create events on a college event website, using a user id and password. Website and database was able to support multiple concurrent users at the user, administrator, and superadministrator levels. Advanced features included event feeds from university's events system, social network integration, crash recovery policies, security, etc.

Skills Learned

  • API integration
  • Database management
  • HTML/CSS
